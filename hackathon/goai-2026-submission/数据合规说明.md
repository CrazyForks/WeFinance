# WeFinance 数据来源与合规说明

版本：v1.0（2026-08-08）

## 数据类型与来源

- 用户输入：账单/收据图片（用户拍照或截图上传）、月度预算数字、可信商户白名单、聊天问答文本
- OCR 结构化数据：由 GPT-4o Vision 从账单图片中提取的交易记录（日期、商户、类别、金额、商品明细），不来自任何第三方数据源
- 模型服务：`services/vision_ocr_service.py`（票据识别）、`modules/analysis.py` 与 `services/recommendation_service.py`（消费建议、理财分析）均调用 OpenAI 兼容接口，默认 `newapi.deepwisdom.ai`（`.env` 的 `OPENAI_BASE_URL` 可替换为任意 OpenAI 兼容端点）
- 无外部业务数据、无企业内部系统接入、不采集第三方公开数据

## 处理方式

- 账单图片仅在内存中 base64 编码后随请求发给 Vision API（`services/vision_ocr_service.py:213-214`），不落盘保存原始图片
- 交易记录、预算、聊天记录等结构化数据存放在 Streamlit `session_state` 中，浏览器刷新即清空（无数据库）
- 如需跨会话保留，`utils/storage.py` 提供本地 JSON 文件持久化（默认 `~/.wefinance/data.json`，写权限不足时回退到运行目录），文件明文存储、无加密，仅用于同一台设备的会话恢复，不上传云端
- 未接入任何分析/追踪 SDK，不做用户画像或行为归因

## 授权与边界

- 用户上传账单即视为授权本次会话对该图片做 OCR 识别与后续分析
- 报告与建议明确标注"分析与教育性内容，不构成投资/信贷/保险决策依据"（见 `services/recommendation_service.py` 系统提示词），不替代持牌金融机构、税务或会计专业人员的判断
- 本项目不做实名核验、不采集身份证号/银行卡号等敏感字段；账单图片中若包含此类信息，由用户自行判断是否上传，产品不做额外脱敏处理（已知限制，见官方要求对照清单）

## 第三方依赖披露

| 依赖 | 用途 | 类型 | 说明 |
|---|---|---|---|
| OpenAI 兼容 API（默认 newapi.deepwisdom.ai，模型 gpt-4o） | 账单 OCR、消费分析建议、理财报告生成 | 商业 API | 需配置 `OPENAI_API_KEY`；`OPENAI_BASE_URL`/`OPENAI_MODEL` 可替换为其他 OpenAI 兼容端点 |
| LangChain / langchain-openai | 对话式财务顾问的 Agent 编排（`services/langchain_agent.py`） | 开源库 | 复用同一组 OpenAI 兼容凭据，不单独收集数据 |
| Streamlit Community Cloud | 应用托管 | 平台服务 | 免费层，见官方要求对照清单中的已知部署问题 |

替换路径：模型服务可通过环境变量切换 `OPENAI_BASE_URL`/`OPENAI_MODEL`，代码不绑定任何单一厂商。

## 密钥管理

- 本地开发通过 `.env` 文件配置（git-ignored，`.env.example` 为模板）
- 生产部署通过 Streamlit Community Cloud 的 Secrets 管理界面配置，不提交仓库
- 代码中未发现任何硬编码密钥或将密钥回传前端的路径
